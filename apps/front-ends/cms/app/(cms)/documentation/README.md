# Documentation

This directory contains comprehensive documentation for the Keystone CMS system.

## 📚 Available Documentation

- **Main Documentation Page** (`/documentation`) - Overview and navigation to all documentation
- **RBAC System Guide** (`/documentation/rbac-guide`) - Complete guide to Role-Based Access Control
- **RBAC Developer Cheat Sheet** (`/documentation/rbac-cheatsheet`) - Quick reference for developers

## 🎯 Purpose

The documentation is designed to be:

- **Practical and actionable** - Copy-paste examples you can use immediately
- **Step-by-step** - Clear workflows for common tasks
- **Self-validating** - Built-in testing tools to verify your work
- **Maintainable** - Easy to update as the system evolves

## 🔗 Navigation

Access documentation through:

- **Sidebar**: Documentation link (visible to Global roles)
- **System Page**: Quick reference section
- **Direct URLs**: `/documentation`, `/documentation/rbac-guide`, `/documentation/rbac-cheatsheet`

## 📝 Contributing

When updating documentation:

1. Update the relevant page content
2. Test any code examples
3. Verify links still work
4. Update the main documentation index if needed
